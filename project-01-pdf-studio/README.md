# Project 1: PDF Studio (Offline 29-in-1 Suite)

## Overview
100% client-side, zero-cloud PDF manipulation app built to pass all Everyday Digital Toolkit criteria.

## Key Features & Capabilities
- [x] **Wi-Fi Off Offline Test**: Open `index.html` in browser with Wi-Fi disabled. All vendor libraries are stored in `./vendor/` so everything functions without network.
- [x] **Multi-Page Document Support**: Click the **📄 Load Sample PDF** button to load `sample-document.pdf`.
- [x] **Tools from all 5 Groups**:
  1. *Organise*: Merge, Split, Reorder Up/Down, Rotate 90°, Delete, Duplicate, Extract, Blank Page, Crop.
  2. *Edit*: Add Text, Add Image, Highlight, Draw Pen, Shapes, Whiteout, True Redaction, Sign, Fill Forms.
  3. *Stamp*: Watermark (DRAFT), Page Numbers ('Page X of 50'), Header & Footer, Date Stamp.
  4. *Convert*: Images to PDF, PDF to Images (PNG download), PDF to Raw Text.
  5. *Finish*: Compress (displays Before & After KB comparison), Metadata Editor, Metadata Stripper, PDF Comparison, Password Lock.
- [x] **Redaction Security**: Redacting draws an opaque black box directly into the exported PDF stream.
- [x] **External PDF Compatibility**: Saved files open seamlessly in Chrome, Edge, and Adobe Acrobat.
