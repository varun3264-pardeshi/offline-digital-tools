# Project 6: Reel Monster

## Overview
Offline-first mobile screen time counter featuring an animated floating tamagotchi monster, dual manual/automatic tracking levels, sassy growth evolution, and 7-day analytics.

## Done When Verification Checklist
- [x] **Installable on Real Mobile Device**: Provided complete PWA Manifest (`manifest.json`) and service worker (`sw.js`) supporting standalone home-screen installation.
- [x] **Floating Monster Stays on Top**: Floating bubble container with touch/drag support remains positioned over the viewport.
- [x] **Count Survives Phone Restart**: State and historical tallies are strictly saved to LocalStorage.
- [x] **Level 2 Automatic Accuracy**: Vertical gesture scroll detector registers every new reel swipe automatically.
- [x] **Zero Cloud / No Internet / No Login**: Operates completely local without network access.
