# Everyday Digital Toolkit — 17 Self-Contained Offline Tools

A complete collection of **17 practical, self-contained tools** for documents, exam photos, resumes, mock tests, billing, browser productivity, video editing, and web design. Every tool runs **100% locally in the browser** with zero cloud dependencies.

- 🌐 **Live Website (Master Toolkit Hub)**: https://varun3264-pardeshi.github.io/offline-digital-tools/
- 📦 **GitHub Repository**: https://github.com/varun3264-pardeshi/offline-digital-tools

---

## 🚀 Quick Start

1. **Open the Master Toolkit Hub**:
   Open [`index.html`](./index.html) in any modern browser (Chrome, Edge, Brave, Firefox).
2. **Or Launch Any Tool Directly**:
   Every tool is self-contained inside its own `project-XX-...` directory with its own `index.html`, `README.md`, `prompts.md`, and sample test files.
3. **Run Automated Verification**:
   ```bash
   python verify_suite.py
   ```

## 🛡️ Architecture & Offline Guarantees

- **100% Offline Execution**: All vendor libraries (`pdf-lib.min.js`, `pdf.min.js`, `pdf.worker.min.js`, `qrcode.min.js`) are bundled locally.
- **Multi-Palette Theme Engine**: Switch seamlessly between `Terracotta`, `Emerald`, `Coral`, `Amber`, `Mulberry`, `Espresso`, and `Obsidian` palettes or press `Ctrl+K` for the Quick Search Spotlight.
- **Strict Content Security Policy (CSP)**: Every tool enforces local-only resource loading and input sanitization.
