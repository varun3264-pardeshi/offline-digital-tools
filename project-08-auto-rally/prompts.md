### Prompt 1: 2.5D Canvas Engine & Auto-Rickshaw Physics
> "Build an arcade auto-rickshaw racing game rendered on an HTML5 canvas at 60 FPS. Implement pseudo-3D perspective road projection with looping track segments. Model vehicle physics with realistic steering inertia, acceleration, and braking."

### Prompt 2: Dual Control Scheme (Keyboard & Touch)
> "Support full desktop controls (Arrow keys / WASD) and on-screen responsive touch controls (Left, Right, Accelerate, Brake pads) so friends can play seamlessly on mobile phones in portrait or landscape."

### Prompt 3: Game Entities (Coins, Potholes, Turbo Boost)
> "Add track collectibles:
> - Golden Coins: +10 score each with ding sound.
> - Road Potholes & Barricades: collision deceleration with spin shake.
> - Nitro Turbo Boost: 2x speed burst with flame particle effects."

### Prompt 4: 3-Lap Race, Timer & Web Audio Synthesizer
> "Implement 3 continuous laps with real-time lap timer (Lap 1/3, 2/3, 3/3). Store all-time best lap and race records in LocalStorage. Use the pure Web Audio API oscillator to synthesize engine hum, coin pickup chimes, turbo whooshes, and crash sounds with an interactive Mute toggle."
