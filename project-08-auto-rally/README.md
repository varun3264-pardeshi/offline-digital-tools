# Project 8: Auto Rally

## Overview
Arcade auto-rickshaw 3-lap racing game running at 60 FPS on HTML5 Canvas with steering physics, golden coin pickups, pothole obstacles, nitro turbo boosts, pure Web Audio API synthesizer, and offline record persistence.

## Key Features & Capabilities
- [x] **Full 3-Lap Race in Flight Mode**: Complete 3-lap loop game runs 100% offline with zero remote assets.
- [x] **Intuitive Zero-Instruction Playability**: Responsive keyboard controls (Arrow keys / WASD) and on-screen mobile touch steering buttons.
- [x] **Fair Crashes and Lap Counting**: Clear hitboxes for coins, potholes, and turbo boost; 3 continuous lap counts with finish celebration.
- [x] **Persistent High Scores**: Best lap/race records are preserved in LocalStorage across browser reboots.
- [x] **Procedural Audio Synthesizer**: Pure Web Audio API generates engine sounds, coin chimes, and crash impacts with a one-click mute button.
