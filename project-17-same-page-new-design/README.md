# Project 17: Same Page, New Design

## Overview
Comparative study demonstrating the transformative power of modern design systems by comparing `before.html` (plain generic web page) with `after.html` (ultra-high fidelity liquid glassmorphism makeover) keeping **100% identical copy**.

## Key Features & Capabilities
- [x] **Both `before.html` and `after.html` exist**: Both source files are present in the directory.
- [x] **The words in both files match 100% verbatim**: Every heading, sentence, date, and link text is identical between `before.html` and `after.html`.
- [x] **The redesign works on a phone**: Responsive viewport meta tag, flexible grid layouts, and touch-friendly padding.
- [x] **3 Core Design Changes & Why Each Helps**:
  1. *Typographic Hierarchy & Contrast*: Shifts from unstyled serif to bold sans-serif with negative letter-spacing and linear gradient fill, establishing instantaneous headline recognition.
  2. *Call-To-Action Affordance*: Replaces plain blue inline link with an elevated glowing cyan-to-blue pill button, boosting user conversion.
  3. *Spatial Chunking & Ambient Glassmorphism*: Structures schedule and speakers into frosted-glass cards with neon iconography, eliminating reading fatigue.
