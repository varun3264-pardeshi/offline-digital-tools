### Prompt 1: Baseline Generation Without Skill (`before.html`)
> "Generate a plain, unstyled HTML page for TECHNOVA 2026 college robotics & code festival without applying any design skills or modern CSS frameworks. Include title, subtitle, register link, track list, 3-day schedule, keynote speakers, and venue details. Save as `before.html`."

### Prompt 2: Design Skill Critique & Evaluation
> "Critique `before.html` using modern web design principles (visual hierarchy, contrast, spatial chunking, typography scaling, call-to-action prominence, and mobile responsiveness)."

### Prompt 3: High-Fidelity Liquid Redesign (`after.html`)
> "Redesign the page into `after.html` using a futuristic liquid glassmorphism design system. Rule: The words in `after.html` must match `before.html` 100% verbatim. Apply ambient fluid mesh glows, tactile gradient CTA buttons, frosted-glass content cards, and responsive mobile layout."

### Prompt 4: 3 Design Changes Rationale & Verification
> "Document the 3 core design improvements (Typographic Hierarchy, CTA Affordance, and Spatial Chunking) and explain why each one helps user comprehension and conversion."
