# Project 2: Form Photo Fixer

## Overview
Offline biometric exam portal photo & signature formatter with face guide overlay and automated step-by-step KB compression.

## Done When Verification Checklist
- [x] **Meets rules of 3+ real forms with official links**:
  1. UPSC Civil Services: 350 × 450 px, 20 KB to 50 KB (Link: [upsconline.nic.in](https://upsconline.nic.in))
  2. SSC CGL / CHSL: 3.5 × 4.5 cm, 20 KB to 50 KB (Link: [ssc.gov.in](https://ssc.gov.in))
  3. IBPS Bank PO: 4.5 × 3.5 cm, 20 KB to 50 KB (Link: [ibps.in](https://www.ibps.in))
  4. NTA JEE / NEET: 3.5 × 4.5 cm, 10 KB to 200 KB (Link: [jeemain.nta.nic.in](https://jeemain.nta.nic.in))
- [x] **Exact filesystem KB size match**: Downloaded `.jpg` verified on local disk to stay strictly under the limit.
- [x] **High-resolution camera photo test**: Tested with high-res sample photo in flight mode / Wi-Fi disconnected.
- [x] **Biometric Face Guide**: Oval guide assists centering face and eye line.
- [x] **Custom Presets**: Full support for custom pixel width, height, and KB threshold.
