# Project 5: Scribbly Notes

## Overview
Offline hand-drawn notebook simulator converting plain typed notes into natural handwritten pages with realistic baseline jitter, letter-spacing variations, and seamless multi-page pagination.

## Key Features & Capabilities
- [x] **3-Page Note Splits with Zero Cut Lines**: The auto-paginator measures discrete 32px line slots and pushes entire lines to Page 2 and Page 3, ensuring no line is sliced in half.
- [x] **Fonts Stored & Offline Ready**: Bundled standard cursive fallbacks (`Caveat`, `Patrick Hand`, `Indie Flower`, local handwriting scripts) enable 100% functionality with Wi-Fi disconnected.
- [x] **Pleasant Reading Quality**: Beautiful collegiate lined notebook styling with left margin red guide, customizable gel ink colors, and natural subtle variations.
- [x] **Export Capabilities**: Clean print dialog produces high-resolution A4 multi-page PDF or printable sheets.
